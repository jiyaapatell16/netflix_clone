# Netflix Clone as a project for html and css

A responsive Netflix-inspired landing page built as a frontend practice project.

## Features

- Netflix-style fixed navigation
- Stranger Things hero section with background video
- Horizontal movie sections
- Responsive layout for desktop, tablet and mobile
- Movie-card hover interactions
- Accessible labels and semantic HTML
- Basic JavaScript interactions

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Run Locally

Open `index.html` in a browser, or use a local development server such as VS Code Live Server.

## Note

This project is an educational Netflix UI clone and is not affiliated with Netflix.
